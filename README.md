# Infinity Print — الكتالوج + لوحة التحكم (Cloudflare)

## الخلاصة: Cloudflare وحده يكفي
| الخدمة | دورها | مطلوبة؟ |
|---|---|---|
| **Cloudflare Workers** | يستضيف الموقع + السيرفر (API) | نعم |
| **Cloudflare D1** | قاعدة البيانات (الأقسام، المنتجات، الإعدادات، **والصور**) | نعم |
| **GitHub** | صندوق رفع للكود فقط، وCloudflare يسحب منه وينشر تلقائيًا | اختياري (موصى به لأنه يغنيك عن تثبيت أي برنامج) |

- كل ما تحذفه من لوحة التحكم (منتج / قسم / صورة / رابط) يُحذف **فعليًا** من قاعدة البيانات، ولا يبقى له أثر.
- الصور تُحفظ داخل D1 نفسها، فلا تحتاج R2 ولا بطاقة بنكية. الخطة المجانية تكفي كتالوجًا كاملًا (5GB).
- رابط لوحة التحكم: `https://اسم-موقعك/admin/` — غير ظاهر في الموقع ولا في محركات البحث.

## خطوات النشر (بدون تثبيت أي برنامج)

### 1) حساب Cloudflare
سجّل مجانًا على dash.cloudflare.com.

### 2) إنشاء قاعدة البيانات
Workers & Pages ← **D1 SQL Database** ← Create database ← الاسم: `infinity-print`.
انسخ **Database ID** من صفحة القاعدة. (لا تحتاج إنشاء جداول، تُنشأ تلقائيًا وتُملأ بمنتجاتك الحالية عند أول زيارة.)

### 3) ضع الـ ID في الإعدادات
افتح ملف `wrangler.jsonc` وبدّل `PASTE_YOUR_D1_DATABASE_ID_HERE` بالـ ID الذي نسخته.

### 4) ارفع المشروع على GitHub
أنشئ حسابًا على github.com ← New repository (اجعله **Private**) ← Upload files ← اسحب كل محتويات هذا المجلد
(`src` و`public` و`wrangler.jsonc` و`package.json`) ← Commit.

### 5) اربط GitHub بـ Cloudflare
Workers & Pages ← Create ← **Import a repository** ← اختر المستودع ← اترك الإعدادات الافتراضية ← Deploy.
بعد دقيقة يظهر لك رابط الموقع `xxxx.workers.dev`.

### 6) كلمة مرور الأدمن
داخل الـ Worker: Settings ← **Variables and Secrets** ← Add ← النوع **Secret** ← الاسم `ADMIN_PASSWORD` ← القيمة كلمة مرور قوية (12 حرفًا فأكثر) ← Deploy.
لتغيير كلمة المرور لاحقًا: عدّل نفس الـ Secret (وتنتهي كل الجلسات القديمة تلقائيًا).

### 7) ادخل اللوحة
افتح `رابط-الموقع/admin/` وسجّل الدخول.

## ربط دومين خاص
Worker ← Settings ← Domains & Routes ← Add ← Custom domain (الدومين يجب أن يكون على Cloudflare).

## تعديل التصميم لاحقًا
عدّل الملفات على GitHub (زر القلم) ← Commit ← يُنشر تلقائيًا. المحتوى (منتجات/نصوص/صور) يُدار من اللوحة فقط ولا يتأثر بالنشر.

## بعد أول تشغيل
يمكنك حذف مجلد `public/seed` من GitHub (صور البداية نُسخت إلى قاعدة البيانات).

## الأمان
- جلسة موقّعة HttpOnly + SameSite=Strict، وحظر 15 دقيقة بعد 5 محاولات فاشلة.
- حماية من الطلبات المزوّرة (فحص Origin).
- يُنصح بإضافة Rate Limiting Rule من Cloudflare على المسار `/api/login`.
